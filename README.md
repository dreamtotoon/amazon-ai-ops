# 亚马逊 AI 智能运营

这是亚马逊美国站 Codex-first 试点的主仓库，管理可复用的团队规则、Skills、确定性脚本、模板与评估集。

## 使用边界

- Git 只保存可复用规则、代码、模板与脱敏评估样本。
- 真实产品资料、原始市场数据、供应商文件、图片素材与审批记录保存在受控产品目录或企业云盘，不提交 Git。
- 所有客观评分和硬性校验必须由脚本完成；模型只负责分析、解释与提出待验证项。
- 最终类目、产品 ID、图片、发布与高风险结论必须人工确认。

## 目录说明

- `项目规则/`：团队数据边界、权限和审核要求。
- `.agents/skills/`：可被 Codex 发现的标准 Skills；目录可使用中文，`SKILL.md` 为固定入口名。
- `脚本/`：确定性评分、清洗与校验脚本。
- `模板/`：产品事实、运行记录、证据索引与审批模板。
- `评估集/`：仅保存脱敏历史案例、回归用例与错误库。
- `产品项目模板/`：真实产品项目的标准目录模板。

## 启动顺序

1. 复制 `产品项目模板/` 到受控工作目录，按产品创建任务。
2. 填写候选产品、产品事实、运行记录和证据索引。
3. 使用 Skills 和脚本产出选品、关键词、Listing、图片 Brief 与审核材料。
4. 通过人工审核后，再将可复用经验沉淀至知识库。
